## 1. Engine + toolchain

- **SQLite 3.42+** (better-sqlite3 binding matches the Mac Studio M4 Max architecture)
- **Migrations:** applied via `server/migrate.js` (idempotent; tracks applied migrations in `schema_migrations` table)
- **Single primary DB** at `data/budgeting.sqlite`; backups via `sqlite3 .backup` daily cron

## 2. Naming conventions

- Table names: `snake_case`, plural
- Column names: `snake_case`
- Primary key: `id TEXT PRIMARY KEY` (UUID v4, generated by app) for portability
- Foreign keys: `*_id TEXT` referencing the parent table
- Timestamps: `created_at INTEGER` (Unix epoch seconds, UTC) + `updated_at INTEGER` (set by trigger on UPDATE)
- Soft delete: `deleted_at INTEGER NULL`; queries always `WHERE deleted_at IS NULL`
- Booleans: `INTEGER` with `CHECK(col IN (0,1))` (SQLite has no native boolean)
- Money: `INTEGER` (cents) — never floats. The UI formats with currency. `last_year_actual_cents`, `this_year_projected_cents`, etc.
- Period fields: `period_1`, `period_2`, ..., `period_12` (monthly actuals) — `_cents` suffix

## 3. Multi-tenant column

Every business table has `company_id TEXT NOT NULL REFERENCES companies(id)`. Single-tenant v1 hardcodes the Company row, but queries are always scoped by `company_id` so future multi-tenant is a config change, not a migration.

### 4.7 `line_items`

The core data: vendor × category × department × year, with projections + actuals.

```sql
CREATE TABLE line_items (
  id                          TEXT PRIMARY KEY,
  company_id                  TEXT NOT NULL REFERENCES companies(id),
  budget_year_id              TEXT NOT NULL REFERENCES budget_years(id),
  department_id               TEXT NOT NULL REFERENCES departments(id),
  category_id                 TEXT NOT NULL REFERENCES categories(id),
  vendor_id                   TEXT REFERENCES vendors(id),  -- nullable
  name                        TEXT NOT NULL,                  -- "Microsoft 365", "Cisco Direct"
  contract_flag               INTEGER NOT NULL DEFAULT 0 CHECK(contract_flag IN (0,1)),
  contract_term               TEXT CHECK(contract_term IN ('monthly','yearly','2yr','3yr','5yr') OR contract_term IS NULL),
  renewal_date                TEXT,                           -- ISO date 'YYYY-MM-DD'
  last_year_actual_cents      INTEGER NOT NULL DEFAULT 0,
  pct_increase_bp             INTEGER,                        -- basis points (e.g. 500 = 5.00%)
  fixed_increase_cents        INTEGER,
  this_year_projected_cents   INTEGER NOT NULL DEFAULT 0,    -- computed by app on insert/update
  notes                       TEXT,
  display_order               INTEGER NOT NULL DEFAULT 0,
  created_at                  INTEGER NOT NULL,
  updated_at                  INTEGER NOT NULL,
  deleted_at                  INTEGER
);

CREATE INDEX idx_line_items_year_dept ON line_items(budget_year_id, department_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_line_items_vendor ON line_items(company_id, vendor_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_line_items_renewal ON line_items(company_id, renewal_date) WHERE contract_flag = 1 AND deleted_at IS NULL;
```

**Computed column note:** `this_year_projected_cents` is computed by the app on insert/update (formula: `last_year_actual + fixed_increase` if provided, else `last_year_actual × (1 + pct_increase_bp / 10000)`). Stored as a column for fast dashboard reads; re-computed in the same transaction as the input change so it can never drift.

### 4.8 `monthly_actuals`

12-period spend per line item.

```sql
CREATE TABLE monthly_actuals (
  id                    TEXT PRIMARY KEY,
  line_item_id          TEXT NOT NULL REFERENCES line_items(id),
  company_id            TEXT NOT NULL REFERENCES companies(id),
  period_1_cents        INTEGER NOT NULL DEFAULT 0,
  period_2_cents        INTEGER NOT NULL DEFAULT 0,
  period_3_cents        INTEGER NOT NULL DEFAULT 0,
  period_4_cents        INTEGER NOT NULL DEFAULT 0,
  period_5_cents        INTEGER NOT NULL DEFAULT 0,
  period_6_cents        INTEGER NOT NULL DEFAULT 0,
  period_7_cents        INTEGER NOT NULL DEFAULT 0,
  period_8_cents        INTEGER NOT NULL DEFAULT 0,
  period_9_cents        INTEGER NOT NULL DEFAULT 0,
  period_10_cents       INTEGER NOT NULL DEFAULT 0,
  period_11_cents       INTEGER NOT NULL DEFAULT 0,
  period_12_cents       INTEGER NOT NULL DEFAULT 0,
  updated_at            INTEGER NOT NULL,
  UNIQUE(line_item_id)
);

CREATE INDEX idx_monthly_actuals_line ON monthly_actuals(line_item_id);
```

**Variance derivation (computed by app, not stored):**
`variance_cents = this_year_projected_cents - sum(period_1..12)`

### 4.10 `contracts`

Separate from `line_items` because a contract may span multiple line items (multi-year renewal) and the PDF is the source of truth.

```sql

  company_id              TEXT NOT NULL REFERENCES companies(id),
  vendor_id               TEXT NOT NULL REFERENCES vendors(id),
  contract_amount_cents   INTEGER NOT NULL DEFAULT 0,
  term_months             INTEGER NOT NULL,                 -- 12, 24, 36, 60
  start_date              TEXT NOT NULL,                    -- 'YYYY-MM-DD'
  end_date                TEXT NOT NULL,                    -- 'YYYY-MM-DD'
  renewal_date            TEXT,                             -- 'YYYY-MM-DD' or NULL if no auto-renew
  uploaded_file_path      TEXT,                             -- 'data/uploads/<job_id>/original.pdf'
  parsed_json             TEXT,                             -- raw parser output for replay

  deleted_at              INTEGER
```

## 9. Sample queries (for Phase 3 reference)

```sql
-- Dashboard grand total
SELECT SUM(this_year_projected_cents) AS projected_cents,
       SUM(last_year_actual_cents)    AS last_year_cents
FROM line_items li
JOIN budget_years by ON li.budget_year_id = by.id
WHERE by.company_id = ? AND by.status = 'active' AND li.deleted_at IS NULL;

-- Variance per line item
SELECT li.name,
       li.this_year_projected_cents AS projected_cents,
       COALESCE(ma.period_1_cents,0) + COALESCE(ma.period_2_cents,0) + ... + COALESCE(ma.period_12_cents,0) AS actual_cents,
       li.this_year_projected_cents - (COALESCE(ma.period_1_cents,0) + ... ) AS variance_cents
FROM line_items li
LEFT JOIN monthly_actuals ma ON ma.line_item_id = li.id
JOIN budget_years by ON li.budget_year_id = by.id
WHERE by.company_id = ? AND by.status = 'active' AND li.deleted_at IS NULL;

-- Contracts expiring in next 90 days
SELECT c.id, v.name, c.renewal_date, c.contract_amount_cents
FROM contracts c
JOIN vendors v ON c.vendor_id = v.id
WHERE c.company_id = ?
  AND c.status = 'active'
  AND c.renewal_date IS NOT NULL
  AND julianday(c.renewal_date) - julianday('now') BETWEEN 0 AND 90
ORDER BY c.renewal_date;
```
