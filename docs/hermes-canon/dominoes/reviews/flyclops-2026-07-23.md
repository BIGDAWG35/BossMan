## 5. Tournament engine status

CLOSED, verified live:
  - Bracket generator handles 2/3/4/5/6/7/8/9/16/32/64 player counts with correct byes + rounds.
    - For n=5, n2=4, byeCount=1, totalRounds=2. Top seed auto-seeds into round-2 player1 slot.
    - For n=3, n2=2, byeCount=1, totalRounds=2. Round-2 (the bye vs winner) is created.
    - For n=2, n2=2, byeCount=0, totalRounds=1 (the single match is the final).
  - Server creates round-1 matches with best_of_n=3 in `matches` table.
  - Server match.applyMove INCREMENTS `games_player1_wins`/`games_player2_wins` per game end (not overwrite).
  - When 2 wins reached, server triggers `advanceBracket(tournamentId, matchId, winnerId)`.
  - advanceBracket creates the next round match row in `matches` table when both slots are filled.
  - advanceBracket chains `nextMatchId` references so future advances still resolve.
  - Top-seed BYE is auto-seated into round-2 player1 slot by the bracket-generator.
  - Live verified:
      - Create tournament -> invite 6 players -> start ->
        bracket data has 2 R1 matches + 1 R2 final + 1 bye to top seed.
      - Round-1 match rows persisted (round 1 of best-of-3).
      - After M1 winner forced: advanceBracket was called and a new match row for round-2 was inserted with both player slots filled.
