## Section 1 — Kanban Schema (Final)

### Board

| Property | Value |
|----------|-------|
| Board ID | `bossman` |
| DB path | `~/.hermes/kanban/boards/bossman/kanban.db` |
| Rule | **All work tracked here. No work happens off-board.** |
| Owner | BossMan |

### Status Definitions

| Status | Meaning |
|--------|---------|
| `inbox` | Raw incoming — not triaged yet |
| `planned` | Triaged, queued, ready to work |
| `running` | Work in progress |
| `client_testing` | Build/test-ready — with testers |
| `feedback_review` | Feedback received — being processed |
| `blocked` | Waiting on external dependency or approval |
| `awaiting_approval` | Marcelo must approve before proceeding |
| `done` | Completed and verified |

### Card Lifecycle

```
inbox → planned → running → client_testing → feedback_review → done
                 ↑
           (blocked ← awaiting_approval)
```

### Priority Levels

| Priority | Meaning |
|----------|---------|
| 1 | Critical — must address before anything else |
| 2 | High — schedule this phase |
| 3 | Medium — backfill when capacity allows |

### Ownership

| Role | Owns |
|------|------|
| Marcelo | Human decision authority, final approvals |
| BossMan | Orchestrator, all routing, board owner |
| Hermes profiles | Execute specific domains per routing rules |

## Section 2 — Handoff Packet Format (Standard)

### BossMan → Agent (any)

```
From: BossMan
To: [agent_id]
Task ID: [kanban_card_id]
Priority: 1-3
Created: [ISO timestamp]

### Task Summary
[1-3 sentences — what, why, and what success looks like]

### Deliverables
- [ ] [Deliverable 1 — specific and testable]
- [ ] [Deliverable 2]

### Constraints
- [Hard constraint 1 — what NOT to do]
- [Hard constraint 2]

### Source Docs
- [File path] — required reading before starting
- [File path] — reference only

### Success Criteria
[How BossMan evaluates completion]

### Escalation
If blocked: comment on card + @mention BossMan. Do not wait.

*Generated by BossMan. All work authorized here.*
```

### Agent → BossMan (completion report)

```
From: [agent_id]
To: BossMan
Task ID: [kanban_card_id]
Status: ✅ Complete / ⚠️ Partial / 🔴 Blocked
Completed: [ISO timestamp]

### What Was Done
[Description of actions taken]

### Deliverables
- [x] [Deliverable 1] — ✅ done / ⚠️ partial
- [ ] [Deliverable 2] — reason if not done

### Files Modified
- [Path] — [change summary]

### Issues / Blockers
[Any remaining issues]

*Reported by [agent_id] to BossMan via Kanban card [ID].*
```
